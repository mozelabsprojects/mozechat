## Overview

Mozechat is an encrypted communication platform engineered to eliminate digital footprints. No plaintext data, media, or user identities are ever exposed to the server. Encryption keys are generated and stored exclusively on client devices.

## Core Features

* **Zero-Knowledge Architecture:** AES-GCM client-side encryption for text, media, voice notes, and location data. Ephemeral rooms leave no traces upon exit or destruction.
* **Panic Camouflage:** One-tap decoy mode transforming the interface into an authentic, working calculator. Native navigation and gestures are locked down until the secret mathematical PIN is evaluated.
* **Tap to Reveal:** Passive blur shielding guards against shoulder surfing. Message contents resolve only during deliberate touch-and-hold gestures.
* **Anonymous Audio:** Built-in robotic frequency modulation masking user voice signatures before transmission.
* **60–120 FPS Fluid Interface:** Optimized render pipeline featuring hardware-isolated repaint boundaries, elastic swipe-to-reply, double-tap shield reactions, and dynamic bitmap memory caching.
* **Direct OTA Updates:** Seamless in-app update management connected directly to official GitHub Releases.
